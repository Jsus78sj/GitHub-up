# Privacy Policy · GitHub Nexus

_Last updated: October 21, 2026_

GitHub Nexus is a client-side tool for uploading ZIP archives to your own GitHub repositories.

**Data we collect:** None. The app has no servers, no analytics, no ads, and no tracking.

**Your GitHub token:** Stored only on your device, encrypted with the Android Keystore. It is sent only to `api.github.com` to perform the actions you request, and is deleted when you tap Disconnect or uninstall the app.

**Your files:** ZIP archives are read on your device and uploaded directly to the GitHub repository you choose. They are not sent anywhere else.

**Network access:** The app connects only to GitHub (`api.github.com` and GitHub avatar images). All connections use HTTPS.

**Children:** The app is not directed at children under 13.
