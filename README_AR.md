# GitHub Nexus · تطبيق أندرويد (نسخة 1.5.0 · كل المراحل)

## وش تغيّر عن الملف الأصلي
- فصلت الملف الواحد (76KB) إلى: `www/index.html` + `www/css/styles.css` + `www/js/app.js`.
- شلت كل روابط الـ CDN:
  - Tailwind (cdn.tailwindcss.com) ← يتبنى محلياً بنفس النسخة v3، يعني الشكل نفسه بالضبط.
  - Lucide `@latest` ← مثبّت على **0.469.0** (ما يتغير فجأة).
  - JSZip ← **3.10.1** محلي.
  - خطوط Google ← Inter و JetBrains Mono كملفات woff2 داخل التطبيق.
- 5 أيقونات قديمة غيّرت أسماءها للأسماء الجديدة الرسمية (عشان ما تختفي بالتحديثات):
  `alert-triangle→triangle-alert`, `check-circle-2→circle-check`, `loader-2→loader-circle`, `upload-cloud→cloud-upload`, `plus-circle→circle-plus`.
- `Authorization: token` ← `Authorization: Bearer` (الصيغة الموصى بها، تشتغل مع classic و fine-grained).
- أضفت **Content-Security-Policy**: التطبيق ما يقدر يتصل إلا بـ GitHub API (حماية للتوكن).
- أضفت `theme-color` للون شريط أندرويد.

## التشغيل (مرة وحدة)
تحتاج Node.js 18 أو أحدث.
```
npm install
npm run build
npm run serve
```
افتح http://localhost:5173

`npm run build` يسوي 3 أشياء:
1. ينسخ JSZip و Lucide والخطوط إلى `www/`
2. يبني Tailwind إلى `www/css/tailwind.css`
3. يفحص إن ما في ولا رابط خارجي باقي (غير GitHub API)

## اختبار المرحلة 1 (لازم ينجح قبل المرحلة 2)

## المرحلة 2: تغليف أندرويد (Capacitor 7)

### المتطلبات
- Node.js **20** أو أحدث
- Android Studio (Ladybug أو أحدث) + Android SDK 35
- JDK **21** (يجي مع Android Studio)

### أول مرة
```
npm install
npm run android:init
npm run android:open
```
بعدها في Android Studio: شغّل على جوالك (▶) أو Build ← Build APK.

### بعد أي تعديل على الكود
```
npm run android:sync
```
أو مباشرة على جوال موصول بـ USB: `npm run android:run`
أو APK تجريبي بدون فتح Android Studio: `npm run android:apk`
← الملف يطلع في `android/app/build/outputs/apk/debug/app-debug.apk`

### وش أضافت المرحلة 2 (`www/js/native.js`)
| الميزة | التفاصيل |
|---|---|
| حفظ التوكن الآمن | ينحفظ مشفّر في **Android Keystore** بعد أول دخول ناجح، والتطبيق يدخل تلقائياً بعدها. زر Disconnect يمسحه. لو التوكن انتهى ينمسح تلقائياً. |
| زر الرجوع | يقفل المودال المفتوح. أثناء الرفع ما يطلعك (يعطيك تنبيه). غير كذا يصغّر التطبيق بدل ما يقفله. |
| الإنترنت | تنبيه فوري لو انقطع أو رجع. |

| الشكل | شريط حالة داكن بلون التطبيق، شاشة بداية بدون وميض أبيض، ومراعاة حواف الشاشة (النوتش وشريط التنقل). |
| المتصفح | نفس الملف يشتغل في المتصفح عادي، بس بدون هذي الميزات، والتوكن ما ينحفظ أبداً هناك. |

**إصلاح:** 3 أيقونات في الإشعارات (نجاح/خطأ/تحذير) كانت بالأسماء القديمة داخل الـ JS، تصلّحت.

### اختبار المرحلة 2 على الجوال
1. افتح التطبيق ← ادخل بالتوكن ← اقفل التطبيق نهائياً ← افتحه: لازم يدخل مباشرة.
2. افتح مودال "Create Repo" ← اضغط رجوع: لازم يقفل المودال بس.
3. اطفي الواي فاي: لازم يطلع تنبيه.
4. اختار ZIP من مدير الملفات: لازم يفتح ويقرأ الملف.
5. Disconnect ← اقفل وافتح: لازم يطلب التوكن من جديد.

### لو صار خطأ

- خطأ Gradle/JDK ← من Android Studio: Settings ← Build Tools ← Gradle ← Gradle JDK = 21.
- نسخة plugin ما تتوافق مع Capacitor 7 ← `npm ls @capacitor/core` وارسل لي الخطأ.
- تبي تفحص الـ WebView من كروم: غيّر `webContentsDebuggingEnabled` إلى `true` مؤقتاً، وافتح `chrome://inspect`.

## المرحلة 3: الرفع السريع (`www/js/deploy.js`)

### الفرق
| | قبل | بعد |
|---|---|---|
| طريقة الرفع | ملف ورا ملف | 6 ملفات بنفس الوقت |
| طلبات لمشروع 200 ملف | ~400 + تأخير ثابت | ~205 (وأقل بكثير لو أغلب الملفات ما تغيرت) |
| عدد الـ commits | واحد لكل ملف (200 commit) | **commit واحد** |
| الملفات اللي ما تغيرت | تنرفع من جديد | **تتخطى** (مقارنة git SHA على الجوال) |
| الحذف بـ Full Sync | طلبين لكل ملف + commit | داخل نفس الـ commit، صفر طلبات إضافية |
| فشل بالنص | الريبو يصير نص محدّث | **الريبو ما يتأثر أبداً** |
| حد GitHub (rate limit) | يفشل بصمت | ينتظر ويكمل تلقائياً |
| انقطاع لحظي / خطأ 5xx | الملف يفشل | إعادة محاولة (حتى 4 مرات) |

### إضافات
- **تنظيف تلقائي:** `__MACOSX/` و `.DS_Store` و `Thumbs.db` و `desktop.ini` ما تنرفع.
- **المجلد الجذري:** لو كل الملفات داخل مجلد واحد (مثل `my-project/...`)، يطلع لك خيار يرفع المحتوى مباشرة لجذر الريبو (مفعّل افتراضياً).
- **ما في تغيير؟** ما ينعمل commit فاضي، يقولك إن كل شي محدّث.
- **أحد رفع بنفس الوقت؟** يعيد بناء الـ commit فوق آخر نسخة تلقائياً مرة وحدة.
- **Submodules** تبقى زي ما هي بـ Full Sync.
- رسالة commit واضحة: `deploy: 12 changes (+3 ~8 -1)`.
- مسارات الملفات صارت تنعرض بأمان في السجل (حماية من HTML داخل أسماء الملفات).

### تم اختباره على ريبو وهمي
Full Sync مع مجلد جذري + ملفات قمامة + 429 من GitHub ✓ · إعادة رفع نفس الـ ZIP (بدون commit) ✓ · Partial يضيف ملف بدون ما يمس الباقي ✓ · صحة حساب git SHA ✓

### ملاحظة
الريبو الفاضي تماماً (بدون أي commit) ما يقبل Git Data API. أنشئ الريبو مع خيار README أول مرة (موجود في مودال Create Repo).

### اختبار المرحلة 3 على الجوال
1. ارفع مشروع كامل Full Sync ← شوف في GitHub: commit **واحد** بس.
2. ارفع نفس الـ ZIP مرة ثانية ← لازم يقول "No changes".
3. عدّل ملف واحد وارفع ← لازم يرفع ملف واحد بس وينتهي بثواني.
4. اطفي النت بنص الرفع ← لازم يفشل برسالة "الريبو ما تأثر"، وفعلاً GitHub ما يتغير.

## خيارات سرعة الرفع
تحت "Deployment Strategy" صار في 4 خيارات، واختيارك ينحفظ للمرة الجاية:

| الخيار | ملفات بنفس الوقت | متى تستخدمه |
|---|---|---|
| 🐢 Safe | 2 (مع فاصل 250ms) | نت ضعيف، أو ريبو ضخم (آلاف الملفات) |
| ⚡ Balanced | 6 | **الافتراضي**، مناسب لأغلب الحالات |
| 💨 Fast | 10 | واي فاي قوي أو 4G/5G |
| 🚀 Turbo | 16 | أقصى سرعة، بس ممكن GitHub يحدّك |

- **تخفيض تلقائي:** لو GitHub رد بـ "rate limit"، التطبيق ينصّف السرعة تلقائياً (مثلاً 16 ← 8 ← 4) وينتظر ويكمل، بدل ما يفشل.
- **عدّاد سرعة حي** في شريط التقدم (مثل `2.4 MB/s`).
- السجل يكتب السرعة المستخدمة في بداية كل رفع.

> نصيحتي: خلك على Balanced. Turbo يفرق بس لما يكون عندك مئات الملفات المتغيرة، ولو الملفات قليلة الفرق ما ينحس.

## المرحلة 4: تجربة الجوال

### الواجهة العربية
- زر **ع / EN** في أعلى الشاشة يبدّل اللغة، واختيارك ينحفظ.
- أول مرة: لو لغة الجوال عربي يفتح بالعربي تلقائياً.
- **RTL كامل:** المسافات والأيقونات (الأسهم) وشجرة الملفات وحركة الإشعارات كلها تنقلب.
- خط **IBM Plex Sans Arabic** للعربي (داخل التطبيق، بدون نت). التوكن والمسارات تبقى بخط برمجي ومن اليسار لليمين.
- الترجمة تشمل كل شي: الأزرار، الإشعارات، الأخطاء، سجل الرفع، شريط التقدم.
- أسماء المستودعات والفروع والمسارات **ما تنترجم أبداً**.
- الترجمات كلها في `www/js/i18n.js`. تبي تعدّل كلمة؟ عدّلها هناك.

### تحسينات الجوال
- مسافات أصغر على الشاشات الصغيرة (360px وأقل).
- الإشعارات بعرض الشاشة وفوق شريط التنقل.
- أزرار بحجم مناسب للمس (40px على الأقل).
- إخفاء تلميحات الكيبورد (⌘Enter، Press Enter) على الجوال.
- إلغاء تأثير "hover" العالق على شاشات اللمس.
- المودالات تنسحب (scroll) لو الشاشة قصيرة.

### رسائل أوضح
- التوكن: يفرّق بين "التوكن غلط/منتهي" و"ما فيه نت" و"GitHub ما يستجيب".
- يحذّرك لو التوكن (classic) ما فيه صلاحية `repo`.

### أمان
- أسماء ووصف المستودعات صارت تنعرض بأمان (كان ممكن وصف فيه HTML يكسر الصفحة).
- حذفت كود الرفع القديم من `app.js` (كان موجود بس غير مستخدم).

### الأيقونة وشاشة البداية
موجودة في `assets/`:
- `icon-only.png`، و`icon-foreground.png` + `icon-background.png` (أيقونة متكيفة لأندرويد 8+)
- `splash.png` و`splash-dark.png`

تتولد كل المقاسات تلقائياً:
```
npm run android:assets
npx cap sync android
```
(`npm run android:init` يسويها لحاله لو بديت من الصفر.)
تبي تغيّر التصميم؟ بدّل الصور في `assets/` بنفس الأسماء والمقاسات (1024×1024 للأيقونة، 2732×2732 للبداية).

### اختبار المرحلة 4
1. اضغط **ع**: كل الواجهة تنقلب عربي ومن اليمين لليسار.
2. ارفع ZIP بالعربي: السجل والإشعارات بالعربي، والمسارات تبقى سليمة.
3. جرّب على جوال صغير أو بوضع 360px في كروم (DevTools ← Device Mode).
4. ثبّت الـ APK وشوف الأيقونة على الشاشة الرئيسية + شاشة البداية.

## المرحلة 5: البناء الموقّع والنشر

عندك طريقتين، **اختار وحدة**:

### الطريقة A: على جهازك (Android Studio)
```
npm run keystore        ← مرة وحدة بس في حياتك
npm run release         ← APK + AAB موقّعين
```
الملفات تطلع في:
- `android/app/build/outputs/apk/release/app-release.apk` ← تثبّته على أي جوال أو توزّعه
- `android/app/build/outputs/bundle/release/app-release.aab` ← لـ Google Play

أو كل وحدة لحالها: `npm run release:apk` / `npm run release:aab`

### الطريقة B: على GitHub (بدون Android Studio أبداً) ⭐
الملف `.github/workflows/android.yml` يبني التطبيق على سيرفرات GitHub مجاناً.
1. ارفع المشروع على ريبو (تقدر ترفعه بتطبيقك نفسه!).
2. بدون أي إعداد: كل رفع على `main` يطلّع **APK تجريبي** في تبويب Actions ← آخر تشغيل ← Artifacts.
3. للنسخة الموقّعة: شغّل `npm run keystore` مرة وحدة على جهازك، وهو يعطيك 4 قيم تحطها في
   Settings ← Secrets and variables ← Actions:
   `NEXUS_KEYSTORE_BASE64`، `NEXUS_KEYSTORE_PASSWORD`، `NEXUS_KEY_ALIAS`، `NEXUS_KEY_PASSWORD`
4. تبي نسخة رسمية؟ سوِّ tag مثل `v1.5.0` ← يطلع APK + AAB في صفحة **Releases** تلقائياً.

### ⚠ مفتاح التوقيع
- يتخزن في `keys/nexus-release.jks`. **انسخه لمكان آمن الحين.**
- لو ضاع: ما تقدر تحدّث التطبيق أبداً (لازم تنشر تطبيق جديد باسم جديد).
- `keys/` و `keystore.properties` في `.gitignore`، **وتطبيقك نفسه يرفض يرفعها** حتى لو كانت داخل الـ ZIP
  (مع `node_modules/` و `.env` و `local.properties`).

### تحديث نسخة
```
npm run version:patch   ← 1.5.0 → 1.5.1 (إصلاحات)
npm run version:minor   ← 1.5.0 → 1.6.0 (ميزات)
npm run release
```
رقم `versionCode` يتحسب تلقائياً من رقم النسخة (1.5.1 = 10501)، فما تنسى تزيده أبداً.

### وش يسوي `scripts/patch-android.mjs` (يتشغل تلقائياً مع كل sync)
- رقم النسخة من `package.json`
- التوقيع من `keystore.properties` أو من GitHub Secrets
- **R8**: تصغير الكود والموارد (APK أصغر) + قواعد تحمي Capacitor والـ plugins من الحذف
- `allowBackup=false`: التوكن المشفّر ما ينسخ لجوال ثاني (كان بيسبب أخطاء بعد الاستعادة)
- `usesCleartextTraffic=false`: ممنوع أي اتصال غير مشفّر

### Google Play
- ارفع ملف **AAB** (مو APK).
- يطلبون **سياسة خصوصية** ← جاهزة في `PRIVACY_POLICY.md`، انشرها كصفحة (مثلاً GitHub Pages) وحط الرابط.
- قسم Data safety: التطبيق **ما يجمع أي بيانات**، والتوكن يبقى على الجهاز ويروح لـ GitHub بس.

### الاختبار النهائي
قائمة كاملة في `TESTING_AR.md`. لا تنشر قبل ما تخلّصها.
